## Overview

StudyBuddy is a minimalist, high-trust platform designed to help students and working professionals find compatible study partners, verify proof-of-work, and accelerate learning with integrated AI tools.

- 🤝 **Smart Matching** — Connect with partners based on skills, availability, and learning goals.
- 🔗 **Verified Proof of Work** — Showcase GitHub, Medium, and Dribbble profiles to build instant trust.
- ⚡ **AI Learning Suite** — Generate 30-day study roadmaps, custom quizzes, and instant note summaries.
- 🌙 **Modern Dark UI** — Distraction-free, fast, and accessible interface built for late-night study sessions.
